# International Olympiad in Informatics (IOI) Subtask Scoring

In Olympiad in Informatics (IOI) mode, problems are partitioned into independent subtasks with specific constraints and partial scores.

## Subtask Structure

- Each subtask contains a set of grouped test cases.
- A subtask is awarded points only if **all test cases** in that subtask pass (`AC`).
- A contestant's total score is the sum of points earned across all subtasks.
- The scoreboard ranks contestants primarily by total accumulated score, breaking ties by last score-improving submission timestamp.
